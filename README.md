# Quanti-Badger

A privacy-focused platform where users can scan their device and determine which data they want to advertise.

## Overview

Quanti-Badger empowers users to take control of their data by:
- Scanning devices to identify advertisable data points
- Allowing users to selectively choose what data to share
- Providing transparent control over data advertising preferences
